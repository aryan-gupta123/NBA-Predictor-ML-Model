# NBA-Predictor-ML-Model
🏀 This project uses machine learning to predict the outcome of NBA games based on box score stats like field goal %, rebounds, assists, and turnovers. I cleaned and explored the data, trained models (starting with logistic regression), and tested them by training on past seasons and predicting more recent games to make it realistic. The results show how certain stats are strong indicators of winning, and the notebook walks through the process step by step with explanations and visualizations. This project is meant to show my skills in data science, sports analytics, and machine learning in a way that’s practical, easy to follow, and fun.
